# Icon pack recortado

Este projeto agora inclui um pacote de ícones recortados a partir das imagens enviadas pelo cliente.

## Pastas
- `curated/`: ícones principais já organizados com nomes semânticos.
- `raw/`: todos os recortes individuais extraídos das imagens originais.

## Ícones já usados no site
instagram, whatsapp, arrow-right, pen, map-pin, clock, headset, calendar, check-circle e outros.
